How to Split a PDF Into Separate Files

Sometimes you only need three pages out of a forty-page document — the signed signature page, the certificate, a single invoice. Splitting a PDF lets you pull exactly the pages you need into their own files. Here is how to do it free, in your browser, with no uploads and no software.

When do you need to split a PDF?

  • Send only the relevant pages instead of a whole heavy document.
  • Extract a signed or certified page for upload to a portal.
  • Divide a book or manual into chapters.
  • Trim a file before sharing so it only contains what the recipient needs.

5

Download each file

Save the new PDFs individually — or all of them — and verify the page numbers.

Tips for clean splits

  • Double-check page numbers — PDFs count the cover page, so confirm which page is which before you split.
  • Name ranges clearly — for example pages 1–5 as "cover and intro", so the files are easy to identify.
  • Compress after splitting — if an extracted range is still large, run it through Compress.
  • Keep the original — splitting creates new files; it does not modify the source document.

💡 Pro tip: split and merge work well together — trim pages from files with Split, then combine the good parts with Merge to build one clean document.
